# Research decision log

## D1: Reject generic visibility-aware layout repair

The full novelty scan found direct overlap with classical visibility-aware
furniture arrangement, museum placement, recent 3D scene repair, and
visibility-constrained cinematography. The broad M05 claim was rejected.

## D2: Retain the signed fixed-route repair task

The surviving task is sparse repair of an existing 3D exhibition layout to a
fixed route's signed reveal/hide schedule, with first-hit attribution and hard
preservation checks. The novelty verdict is conditional, not a claim that no
one has ever studied related visibility optimization.

## D3: Promote after the preregistered pilot

The 15-case pilot passed every declared gate, but its corruption magnitudes
were represented in the action grid. It was used only as a feasibility gate.

## D4: Exclude collapsed LLM layout batch

The exploratory Qwen2.5-7B batch produced 12 valid layouts but selected the
same route family in all 12. It was excluded before repair evaluation. The
formal LLM split uses a balanced stratum schedule and retains every raw output
and rejection.

## D5: Treat procedural formal v1 as a failed benchmark build

The first frozen 300-task batch found procedural layouts for which two declared
premature-reveal strata could not be constructed by any allowed hard-valid
corruption action. Those cases were rejected by code. The batch is retained as
a failed/incomplete run and is not eligible for primary claims.

## D6: Screen final layouts without repair outcomes

The final procedural manifest accepts the first ascending seeds for which all
15 corruption strata are constructable. Screening executes no repair method
and consults no repair outcome. The manifest is frozen before the final run to
avoid selecting layouts based on RevealRepair3D performance.

## D7: Treat repair cost as a debt upper bound

The implemented optimizer ranks hard feasibility, signed schedule loss, and
then edit cost lexicographically. A successful returned repair therefore gives
a feasible upper bound on narrative visibility debt, not an unconditional
minimum-cost estimate. Exact no-op/one-edit enumeration is reported separately
to identify cases where loss and cost optimality are certified in that scope.

## D8: Retain and disclose partial grid overlap in eight compound cases

The final case audit found eight compound severity-2 cases in which the
screen-translation subfault is exactly 1.8 m, one of the formal search steps.
The paired 163-degree yaw subfault is not a search step, so the complete
two-action inverse remains unavailable. The cases are retained rather than
silently excluded. Final evidence reports both the full benchmark and a
post-hoc sensitivity analysis excluding these eight cases; manuscript wording
must distinguish complete-inverse leakage from partial subfault overlap.
