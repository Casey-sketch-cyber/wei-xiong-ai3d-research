# 官方推理设置敏感性

## 参数与配对

在推理前单独提交了方案（`a7bf504dc1fa056a6cbd5946b78a1c243956675f`）。SDXL 使用相同的模型快照、Euler 调度器、画作修复提示、扩张输入掩码和原洞计分。比较组合参数 `0.99 / 8.0 / 20` 与上一轮的 `1.0 / 7.5 / 25`，按顺序分别为 strength、CFG 和请求步数。服务器用固定版 Diffusers 复算得到 19 与 25 个有效去噪步，起始时间步为 901 与 961。设为 0.99 时，VAE 编码的输入已经擦除整个扩张域。配对用同一种子 2026。两套初始化的随机数调用会有差异。[冻结协议](INNOVATION.md#pr-7-复审后的官方推理设置敏感性方案) · [固定版模型卡](https://huggingface.co/diffusers/stable-diffusion-xl-1.0-inpainting-0.1/blob/115134f363124c53c7d878647567d04daf26e41e/README.md) · [固定版推理实现](https://github.com/huggingface/diffusers/blob/v0.35.2/src/diffusers/pipelines/stable_diffusion_xl/pipeline_stable_diffusion_xl_inpaint.py) · [调度器配置](https://huggingface.co/diffusers/stable-diffusion-xl-1.0-inpainting-0.1/blob/115134f363124c53c7d878647567d04daf26e41e/scheduler/scheduler_config.json)

中心掩码的 60 幅在 512 和 1024 各推理一次，原尺度的 16 幅在 512 下各测试六个条件。尺寸内的比较只改上述组合。1024 将冻结受损的 512 裁片放大，再把补全缩回同一计分坐标，比较还涉及掩码扩张范围、插值及尺寸条件。原尺度总体对每件作品的六个条件等权平均，四模型共同分母受 PowerPaint 拦截影响。同遮挡范围的像素模型参考使用独立冻结的共享输入结果。

对局部 LPIPS 和 DISTS 采用原掩码外接框及 8 像素边界。亮度偏移为原洞内输出减参考的平均 Rec.709 加权 sRGB 值，范围按 0–1 归一化，正值表示偏亮。置信区间按作品重抽 10,000 次，为未做多重校正的 95% 百分位区间。

## 分辨率和模型差

## 产物与核验

RTX 3090 的 PyTorch 峰值分配显存为 512 两组 7,354.6 MiB、1024 组 9,179.9 MiB。逐图核对 216 份新产物与冻结图像、掩码、种子、评分身份及 PNG 哈希，复算 MAE，并核对洞外像素。亮度使用的 216 份历史对照 PNG 也按上一轮逐图哈希核实。五项掩码回归测试在本地和服务器均通过。

数据盘 `runs/official-inference-20261119/` 包含三组的图像与评分。`diagnostics/official-summary.json` 的 SHA-256 为 `84e2b505cbc997e06b191eab8e74eeb3a0fca51086ad7b6cd7ec3b53024e8787`，`diagnostics/verified-brightness.json` 的 SHA-256 为 `c0832d0cbd97759abd4cb077e5c0a2538b6e07b0a4b78afe855d081e87827589`。前者含五项指标的配对汇总，后者存逐条件亮度、作品级区间和对应输入哈希。[运行说明](ARCHITECTURE.md#sdxl-模型卡参数敏感性)
