# SDXL 预填充颜色对照

## 冻结方案

本轮只改变送入 SDXL 的受损图在扩张洞内的 RGB。三组均用 512 推理、strength 0.99、CFG 8、20 请求步、固定 Euler 调度器、画作修复提示和种子 2026。复用 PR #9 已保存的黑色结果，新增 RGB 128 中灰和洞外环带均色。方案在 `d5ca4d53eb4367ac1f3e3fa5f18eaaad88622d76` 单独冻结，时间为 2026-11-20 03:37:32 UTC。[预先固定的方案](INNOVATION.md#pr-9-复审后的预填充颜色敏感性方案) · [初始化机制](OFFICIAL_INFERENCE.md#黑色预填充如何进入初始化)

环带是扩张输入掩码外 8 像素的方形邻域，裁在画幅内，按可见 sRGB 像素逐通道求平均并舍入到最近整数。每张输入统一用一个洞外环带平均色填满所有遮挡区域。破损遍布裁片时，参与取均值的环带也可能跨越整个裁片。输入域中整块潜空间网格已遮挡，环带排除整块遮挡范围。三组共享二值输入掩码和管线独立的 `masked_image` 条件路径。最终合成和评分采用未扩张的原掩码。

中心掩码有 60 幅，每幅一个条件。原尺度沿用从这 60 幅抽取的 16 幅，每幅三种破损、两个面积档。MAE 和 Rec.709 亮度偏移在原洞内计算，局部 LPIPS 包含原洞外接框外 8 像素上下文。亮度偏移是输出减参考的 0–1 sRGB 加权值，正值表示偏亮。原尺度整体先在作品内对六条件等权平均。各项差值在同一作品和种子下配对，按作品重抽 10,000 次计算未校正的 95% 百分位区间。

两个裁片协议中，中灰和环带相对黑色的亮度变化区间均高于零。这支持黑色填充在固定 0.99 组合下使生成变暗。原尺度的 MAE 优势在改用环带后进一步扩大。历史 1.0 组合在同一原尺度队列的 MAE 为 0.2730，这个历史比较同时改变了 strength、CFG 和去噪步数。三臂对照识别了 0.99 下的颜色作用，无法把上一轮两套组合的差值拆给各个参数。[历史配对](OFFICIAL_INFERENCE.md#同尺寸结果)

正文保留 `strength=1.0`、CFG 7.5、25 步及对齐掩码作为 SDXL 主比较。固定 0.99 时，仅更换预填充就使两类裁片的 MAE 差越过预设 0.01 实用幅度，故 0.99 单列为敏感性，并列报告黑色、中灰和环带均色。环带组的整体结果适用于这批 512 合成破损和单个种子。逐画材、逐条件和三种配对的明细均在汇总 JSON 中。[决策记录](DECISIONS.md)
