# M03 Q2 confirmatory implementation addendum

Status: frozen before confirmatory input generation or model inference. This
addendum specifies implementation details that were described but not assigned
exact numeric values in `CONFIRMATORY_PROTOCOL.md`. It does not change the
confirmatory claim, cohort order, admission thresholds, models, endpoints, or
publication gate.

## 1. ManifoldPlus output handling

The official ManifoldPlus OBJ output preserves distinct vertex indices at
geometrically coincident locations. Those indices must not be merged after
repair: merging them can create non-manifold edges in an otherwise watertight
official output. The repaired mesh is therefore loaded with processing disabled,
unreferenced vertices are removed, winding is oriented consistently, and the
mesh is exported without geometric vertex welding. This correction was made
after topology-only audits of the first five hash-ranked candidates and before
any confirmatory input was rendered or any model was run.

## 2. V30 fixed views

The canonical D30 rotation remains

```
R0 = [[ 0.8192, 0.0000,  0.5736],
      [ 0.2962, 0.8563, -0.4234],
      [-0.4912, 0.5165,  0.7010]].
```

The two additional views are generated by pre-multiplying `R0` by a world
y-axis rotation of -30 degrees and +30 degrees, respectively. All other camera,
lighting, scale, framing, resolution, and background settings are unchanged.

## 3. S30 severity transforms

The canonical-view photo and its alpha mask are fixed first. The same alpha
mask is attached to every severity image.

- Edge medium is exactly the main C120 edge transform: Canny thresholds 70 and
  160 followed by one 2x2 dilation.
- Edge low is an RGB blend of 65% photo and 35% edge-medium inside the fixed
  foreground.
- Edge high applies a radius-2 grayscale blur, Canny thresholds 120 and 240,
  and one 3x3 dilation, retaining only stronger contours on white.
- Sketch medium is exactly the main C120 sketch transform: grayscale colour
  dodge using an inverted radius-9 Gaussian blur.
- Sketch low is an RGB blend of 65% photo and 35% sketch-medium inside the fixed
  foreground.
- Sketch high applies the same colour-dodge construction with radius 15, then
  downsamples to 128x128 and upsamples to 512x512 with bilinear interpolation
  before a final smooth filter.

Low, medium, and high are encoded as 0, 1, and 2 for the prespecified linear
severity trend. The visual contact sheet is inspected only for empty masks,
label errors, corrupt images, or non-monotonic transform implementation; no
model output is used to revise these definitions.

## 4. Fourth-model compatibility boundary

TRELLIS uses official commit
`442aa1e1afb9014e80681d3bf604e8d728a86ee7` and official
`microsoft/TRELLIS-image-large` weights. The RTX 5090 environment retains
PyTorch 2.8.0 with CUDA 12.8 rather than the repository's older default CUDA
11.8 environment. Dependency-only compatibility changes are permitted only
when they do not alter model weights, samplers, conditioning, step counts,
guidance values, sparse resolution, or mesh decoding. Every such change must
be recorded with a patch and environment freeze.
