# 交给 Claude 的接续任务

可以直接在 Claude Code 中要求：

> 请先阅读仓库根目录 CLAUDE.md 以及 handoff/CURRENT_STATE.md。用中文汇报，优先对 M03 做证据驱动的整体优化。先列出真正影响论文质量的具体问题，然后直接实施可核验的修改，完成代码、图表、正文、参考文献和投稿材料的一致性检查。保留预设主检验未通过的负结果。M02、M05 独立管理，原始数据和模型在远程服务器，仓库内只有轻量证据与源文件。

## 建议顺序

1. 读四模型确认实验协议、数值摘要、证据解释和完整主文，建立逐个论点到证据的对应关系。
2. 检查研究问题、贡献定位、Methods、Results、Discussion 是否支持“模型特定鲁棒性”，清除仍把普遍指标悖论当作已证实结论的段落。
3. 对每段检查内容、逻辑、术语、过度声称和重复表达。正文以 humanizer 起草风格为基础，再采用 20-ml-paper-writing 的科学写作与审稿标准润色。
4. 根据已有 JCDE 官方样本文献分析检查结构和篇幅；涉及现行投稿政策、期刊格式或分区时应重新核实，不能将 2026 年 4 月模板说明当成永不变化的政策。
5. 核对四张当前图：流程、整体结果、代表性案例和稳健性。保留输入来源标签，统一面板字母、字体、对齐、图例、CI、颜色和真实素材。先查看正文实际 includegraphics，再选择要改的源图。
6. 交叉核对全文数值、表格、摘要、图注、Highlights、Alt Text 和 cover letter。不要自动重新运行所有 GPU 推理。
7. 参考文献不少于 30 条；核验本稿实际引用。新增近期文献需要真实主文和可靠元数据支持，不仅看候选池。
8. 检查可移植性、参数、随机种子、对象/视角/输入配对、失败排除、阈值敏感性和统计单位。修复代码时保留冻结结果，新增分析独立输出。
9. 新增或修改图表时使用 nature-figure 的合适后端与真实实验记录。框架图可以编辑已有 PPTX；不要用 AI 改变实验输入、mesh 形状或结果数值。
10. 重新编译主文，检查受影响页面，重建与主文一致的投稿包，并报告尚待作者或服务器处理的具体事项。
