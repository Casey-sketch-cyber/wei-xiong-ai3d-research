## Initial submission file order from checklist

1. Main Document, PDF.
2. Graphical Abstract, PDF.
3. Highlights, DOCX.
4. Checklist, DOCX.
5. Main Document Source File, Word or LaTeX ZIP.

## Important writing and formatting notes observed

- Abstract should be one standalone paragraph and should avoid citations, equations, and reference-dependent wording.
- Use 3 to 6 keywords, each keyword no longer than 3 words.
- Equations should be editable text in Word or LaTeX source and numbered consecutively.
- References use APA-style author-year citation behavior in the template.
- Tables should have captions above the table.
- Figures need clear captions. Alt text is required after conditional acceptance in a separate MS Word file.
- The checklist asks that corresponding-author information remain consistent between ScholarOne and the manuscript.
- JCDE typically allows up to two corresponding authors.

## M03-specific preparation note

For the M03 paper, the safest initial submission route is to draft in LaTeX using `01_manuscript/latex/main.tex`, then package the LaTeX source as the fifth initial-submission file.
