## How this scan is used

The scan is not a literature-review substitute. It is a journal-style calibration set for:

- expected front matter, especially graphical abstract and highlights;
- section order and title conventions;
- figure/table density and placement;
- how JCDE papers connect computational methods to design-engineering workflows;
- how much qualitative evidence, quantitative evidence, and user/design implication discussion should appear in the main text.
