# M03 JCDE manuscript workspace

This directory is the managed writing package for the M03 paper targeting Journal of Computational Design and Engineering.

## Directory map

- `00_journal_template/`: JCDE official template package and notes. Keep this as reference material.
- `01_manuscript/`: working manuscript files. Edit files here, not in the original template folder.
- `02_figures_tables/`: staged M03 figures, tables, captions, and experiment output files for manuscript writing.
- `03_submission_materials/`: files prepared for ScholarOne submission, such as checklist, highlights, graphical abstract, and source zip.
- `04_reviews_revisions/`: future reviewer responses, revised manuscripts, and revision records.
- `05_evidence_audit/`: copied M03 result reports, novelty scan, reproducibility notes, and claim-evidence audit.

## Current staged materials

- Official JCDE package zip: `00_journal_template/source_zip/_JCDE_All_Template_and_Checklist_April_21_2026.zip`
- Cleaned extracted package: `00_journal_template/original_package/`
- Unpacked LaTeX template: `00_journal_template/latex_template_unpacked/`
- Working LaTeX copy: `01_manuscript/latex/`
- M03 figure/table outputs: `02_figures_tables/m03_experiment_outputs/`

## Working rule

Use `01_manuscript/latex/main.tex` as the first LaTeX drafting target. Keep the original JCDE files untouched unless the journal releases a newer template.
