# 03 分析计划

分析按读者的实际问题组织（A1–A8），每个问题对应论文 Results 的一个小节。新分析脚本放在 `experiments/m03_revision_20261109/analyze_revision.py`，作图脚本为 `make_revision_figures.py`。可以 import 原 `analyze_confirmatory.py` 的 `bootstrap_mean`、`holm_adjust`、`interaction_test` 等函数，不复制修改原文件。

## 基本约定

| 项目 | 规定 |
| --- | --- |
| 主协议 | `sim`（关口 1 通过时）；否则 `camera` 为主、`sim` 为敏感性 |
| 主几何终点 | `sim_fscore_0.05` 与 `sim_voxel_iou_128` |
| 次要终点 | 其他阈值的 F-score、Chamfer、法向一致性、IoU@64、六视角剪影 IoU 与法向渲染相似度、连通分量、封闭性 |
| 姿态/尺度终点 | `camera_x − sim_x` 的差值，`align_sim_rotation_angle_deg`，`abs(log(align_sim_scale))` |
| 独立单位 | 对象（n = 120）。随机模型两颗种子先在对象内取平均 |
| 配对方式 | 同对象、同模型、同种子、同视角的风格输出减去照片输出，记为 Δ |
| 区间 | 对象聚类 bootstrap，99% 置信区间，重抽样 20,000 次，固定种子 20261109 |
| 多重比较 | 每个分析族内 Holm 校正（族的划分写在各小节） |
| 报告方式 | 效应量 + 区间为主，p 值为辅；不再使用“证据门槛通过/未通过”的表述 |

## A1 照片输入下的基线

- 每个模型在照片条件下的形状指标均值与区间（`sim` 协议）。
- 同时报告 `camera` 协议的值和姿态/尺度终点，说明逐样本对齐前后差多少。
- 产出：表 2（基线）。

## A2 非照片输入下几何退化多少

- 对 4 模型 × 5 风格（E4 完成后为 6 风格）的每一格，计算 ΔF@0.05、ΔIoU@128、Δ剪影 IoU 的均值与区间。
- 多重比较族：每个终点内的 20（或 24）个格子，Holm 校正。
- 模型 × 风格交互：沿用原稿的对象聚类稳健 Wald 检验，用于 ΔF 与 ΔIoU 两个终点。
- 产出：图 2（三个终点的热图，格子内标均值，区间跨零的格子用浅色或斜线标出）。

## A3 照片上的排名还成立吗

- 每种输入条件下，按 `sim_fscore_0.05` 和 `sim_voxel_iou_128` 的对象平均值给四个模型排名。
- 用 bootstrap 估计“照片排名第一的模型在该风格下仍排第一”的概率，以及排名与照片排名的 Kendall τ。
- **失败率**：预先定义失败为“风格输出的 `sim_fscore_0.05` 低于同对象照片输出的 50%”，或网格为空、或连通分量比照片输出多 10 个以上。阈值在看结果前写入 DECISIONS.md。报告每模型每风格的失败率与 Wilson 区间。
- 产出：图 3（左：各条件下的排名变化；右：失败率）。

## A4 退化与输入线索的关系（E3）

- 对每个模型 × 风格，计算 ΔF、ΔIoU 与 `ink_coverage`、`edge_density`、`fg_bg_contrast` 的 Spearman 相关，同一模型内 Holm 校正。
- 按 `ink_coverage` 分成三档（三分位数）画平均退化。
- 报告 E3 预定义的“近乎空白”输入剔除前后的 A2 主结果。
- 这是关联分析，论文中不写因果。
- 产出：图 5。

## 作图要求

- 使用真实实验输入和网格渲染，不用生成模型重画。
- 统一字体、面板字母（A、B、C）、配色（四个模型固定颜色，色盲友好）。
- 每张图同时导出 PDF（矢量）和 600 dpi PNG。
- 热图格子标数值，区间跨零的格子要能一眼看出。
