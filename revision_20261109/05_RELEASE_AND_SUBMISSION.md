# 05 公开发布与投稿前检查

## 1. 公开代码仓库

当前仓库 `wei-xiong-ai3d-research` 已设为公开，但它是内部交接仓库：含 CLAUDE.md、AGENTS.md、交接文档、作者邮箱、服务器路径、M02/M05 等无关内容，不适合写进论文的数据可用性声明。

**建议：** 另建一个干净的发布仓库（例如 `paired-image-to-3d-benchmark`），只放：

| 内容 | 来源 |
| --- | --- |
| 输入生成脚本（渲染、五种滤镜、lineart） | `$EXP/render_*`、E4 新脚本 |
| 推理脚本（四个模型，含冻结提交号与参数） | `$EXP/run_*_confirmatory.py`、E2 新脚本 |
| 评估与配准代码 | `evaluate_confirmatory_model.py`、`alignment_core.py`、`reevaluate_aligned.py` 及测试 |
| 分析与作图脚本 | `analyze_revision.py`、`make_revision_figures.py` |
| 对象清单与调度表 | `c120_manifest.csv`、调度 CSV（把服务器绝对路径改成相对路径或占位符） |
| 汇总结果 | 对象级结果 CSV（不含网格） |
| README | 环境、复现步骤、每一步的预期输出与耗时、许可证 |

不放：网格、权重、GSO 原始资产（只给获取方式和对象标识）、任何凭据。

用 Zenodo 关联 GitHub 发布一个版本，获得 DOI，写进论文的 Data availability。许可证建议代码 MIT 或 Apache-2.0，结果表 CC BY 4.0，由作者确认。

另外：如果不希望投稿前公开内部交接材料，可以在发布仓库建好后把当前仓库改回私有。
