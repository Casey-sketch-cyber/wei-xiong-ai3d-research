# M03 改稿方案（2026-11-09）

这套文档是 M03 被 JCDE 拒稿后的改稿方案，目标是把论文改到可以投普通开源三区或四区期刊并被接收的水平。执行者（Codex 或人）按 [CODEX_TASKS.md](CODEX_TASKS.md) 的顺序做，遇到判断问题回到本目录的对应文档。

## 一句话策略

先修评测里的姿态配准问题，再把论文从“我们的预设假设被否定了”改写成“四个开源 image-to-3D 模型面对草图和插画输入时几何会怎样变化”的正面基准研究。

不加新模型，不扩对象数，不做人评，不做新方法。

## 为什么要改（摘要）

详见 [01_DIAGNOSIS.md](01_DIAGNOSIS.md)。

1. **评测很可能在测姿态误差。** 照片条件下预测体积与真值之比约为 1，但体素 IoU 中位数只有 0.09–0.18。原因是真值被旋转到倾斜的输入视角坐标系，而对齐只允许 90° 轴置换，不做逐样本旋转搜索。
2. **新颖性被 Cue3D（NeurIPS 2025）覆盖。** 它用 7 个模型、GSO 412 个对象和 Toys4K 做了类似的线索扰动研究，原稿只用一句话带过。
3. **叙事以自设假设失败为中心。** 读者不知道也不关心 RG 统计量，剩下的正面结论“鲁棒性因模型而异”又过于可预期。
4. **风格只是滤镜，且保留精确遮罩。** colour-dodge 素描在浅色物体上接近空白图，会被说成“信号消失而非风格”。

## 决策关口

整个方案只有两个需要停下来判断的点。

**关口 1（E1 小试后）：** 20 个对象照片条件下，`sim` 协议的体素 IoU 中位数是否比 `camera` 协议高出至少 0.15？

- 是：证实配准问题，全量重评估，论文以 `sim` 协议为主结果。
- 否：配准不是主因，论文仍以 `camera` 协议为主，但要在方法和讨论中正面解释基线偏低，并把 `sim` 结果作为敏感性分析。两条路都把结果写进 `revision_20261109/DECISIONS.md`。

**关口 2（E1–E4 全部完成后）：** 用新数据核对 04_MANUSCRIPT.md 里的每条预期主张。主张以数据为准，不以本方案的预期为准。
